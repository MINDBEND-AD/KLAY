# M0 manual checks — DAW smoke test (FR-007, partial)

**Who:** product owner. **Hosts (plan decision 2):** Ableton Live, Reaper, FL Studio.
**Goal:** the empty plugin loads, plays and closes cleanly in each host. In M0 the plugin makes no sound; any
audible output is a failure.

## Before you start

1. Build the Release plugin, or download the `Klaymore-vst3-<commit>` artifact from the latest green CI run:

   ```powershell
   cmake --preset vs2026
   cmake --build --preset release
   ```

2. Copy the whole bundle folder `build\plugin\KLAY_artefacts\Release\VST3\Klaymore.vst3` to
   `C:\Program Files\Common Files\VST3\` (needs administrator rights). Replace an older copy if there is one.
3. Note the commit you test: `git log --oneline -1`.

## Steps (repeat in each host)

| # | Step | Expected result |
| --- | --- | --- |
| 1 | Rescan plugins (Live: Preferences → Plug-Ins → Rescan; Reaper: Preferences → Plug-ins → VST → Re-scan; FL Studio: Options → Manage plugins → Find plugins) | The scan finishes without an error or a crash |
| 2 | Find the plugin in the browser | Listed as an instrument named **Klaymore**, vendor **MINDBEND AD** (Live, FL) / "VST3i: Klaymore (MINDBEND AD)" (Reaper) |
| 3 | Load Klaymore on a new instrument / MIDI track | Loads without an error; the track shows a stereo output |
| 4 | Open the plugin window | Dark window showing "Klaymore" and "MINDBEND AD \| v0.1.0" |
| 5 | Close and reopen the plugin window twice | No crash, the window looks the same |
| 6 | Play a few MIDI notes (piano roll clip or MIDI keyboard) with the transport running for ~30 s | Silence; the track meter stays at zero; no clicks, no CPU spike |
| 7 | Change the audio buffer size (e.g. 64 → 1024) and the sample rate (e.g. 44.1 → 96 kHz) in the host's audio settings while the plugin is loaded, then play notes again | No crash, still silent |
| 8 | Save the project, close it, reopen it | The plugin is restored on its track without an error message |
| 9 | Duplicate the track (second instance), play notes on both | Both instances load and stay silent |
| 10 | Delete the plugin from the track, then close the project and the host | The host closes normally (no crash dialog, no hanging process in Task Manager) |

## PO decisions (2026-10-19)

1. **Signalsmith pitch accuracy:** accepted with the default preset; judged in LT-2. **Changed in 1.12, please
   confirm:** at kick fundamentals Signalsmith's pitch shift was 45 cents sharp (not ~8), so pitch shifts are now a
   time-stretch by the pitch ratio plus a Repitch back to length (within ±2 cents). LT-2 compares the sound.
2. **Level at long stretches:** the renderer compensates. Done: stretched parts are scaled to the input RMS, so the
   level stays within ±1 dB at every factor (tested).
3. **Repitch mode:** default mode is Stretch. In Repitch mode the Pitch knob is greyed out, so the Stretch knob is
   the varispeed control (length and pitch change together). Spec updated (FR-106, UI-007, decision log). To do: add the
   mode switch to the wireframes before M3. The renderer follows it (done, tested).
4. **Factory samples:** staging folder `C:\dev\KLAY-samples\` with one sub-folder per layer role (Kick, Rumble, Drive,
   Crunch, Transient, Texture). It is outside the repo on purpose: the repo is public (AGPL) and the samples are
   not. Needed for 1.17 (LT-1: 10–15 parts covering punches, crunches/tails, transients and rumbles).

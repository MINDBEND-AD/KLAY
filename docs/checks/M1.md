   confirm:** at kick fundamentals Signalsmith's pitch shift was 45 cents sharp (not ~8), so pitch shifts are now a

   mode switch to the wireframes before M3. The renderer follows it (done, tested).

## Assumption checks AC-1–AC-4 (task 1.16)

Measured 2026-10-19 on the dev machine (AMD Ryzen 9 7945HX, Release build) with `klay_tests "[bm]" -s`
(`tests/plugin/AssumptionChecks.cpp`; also part of `ctest`). Synthetic fixture parts; one follow bus = the body on
Main, three = body (Main), crunch (A1), rumble (A2), plus a fixed transient.

| Check | Target | Result | Verdict |
| --- | --- | --- | --- |
| AC-1 cache RAM (NFR-014) | ≤ 128 MB per instance | Per cached note: buses × kick length × 8 bytes. Root ±12 (24 notes) fits in every case up to a 1/2-note kick (worst 52.7 MB: 96 kHz, 1/2, 3 buses); 1 bar at 96 kHz with 3 buses needs 105.5 MB. The whole 0–127 range exceeds 128 MB from 1/2 note at 44.1 kHz with 3 buses (128.2 MB) up to 558 MB (1 bar, 96 kHz, 3 buses): there the LRU cap evicts (UT). | Pass; cap confirmed as needed |
| AC-2 cache build time (NFR-015) | root ±2 < 100 ms, ±12 < 1 s | 48 kHz, 1/4 at 150 BPM: ±2 in 45 ms (1 bus) / 46 ms (3 buses); ±12 in 287 / 293 ms; all 127 notes in 1.5 / 1.6 s (~12 ms per further note). | Pass |
| AC-3 playback CPU (NFR-002, playback part) | whole plugin < 5 % of one core | 48 kHz / 128 samples, a kick every 400 ms, 3 follow buses + fixed: 0.04 % cached, 0.14 % through the Repitch fallback. FX chains (M4) are not in yet. | Pass for M1 |
| AC-4 latency (FR-125, NFR-003) | 0 added samples | Note-on at sample 37 → first output sample at 37, for a cached and for a fallback note (processor level). | Pass |

Design changes these checks drove: the cache shifts the buses of a note in parallel (±2 with 3 buses took 130 ms
before), and the exact-pitch method (time-stretch + Repitch) is limited to a 0.25–4× internal stretch (about ±24 st);
farther notes use Signalsmith's own pitch shift, which cut the full-range build from 46 s to 1.5 s.

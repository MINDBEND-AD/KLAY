## PO decisions (2026-10-19)

1. **Signalsmith pitch accuracy:** accepted with the default preset; judged in LT-2. **Changed in 1.12, please
   confirm:** at kick fundamentals Signalsmith's pitch shift was 45 cents sharp (not ~8), so pitch shifts are now a
   time-stretch by the pitch ratio plus a Repitch back to length (within ±2 cents). LT-2 compares the sound.
2. **Level at long stretches:** the renderer compensates. Done: stretched parts are scaled to the input RMS, so the
   level stays within ±1 dB at every factor (tested).
3. **Repitch mode:** default mode is Stretch. In Repitch mode the Pitch knob is greyed out, so the Stretch knob is
   the varispeed control (length and pitch change together). Spec updated (FR-106, UI-007, decision log). To do: add the
   mode switch to the wireframes before M3. The renderer follows it (done, tested).

### 0. Setup

1. Build Release (`cmake --build --preset release`) and install the plugin as in `docs/checks/M0.md` step 1–2.
2. Put the factory parts in `C:devKLAY-samples<Role>` (Kick, Rumble, Drive, Crunch, Transient, Texture):
   10–15 parts covering punches, crunches/tails, transients and rumbles (LT-1 step 1).
3. Generate the listening material (48 kHz, 24-bit, level-matched to each original part):

   ```
   build	oolsender-cliklay_render_cli_artefactsReleaseklay_render_cli.exe listening --samples C:devKLAY-samples --out C:devKLAY-listening
   ```

   It writes `LT-1`, `LT-2` and `AC-5` under `C:devKLAY-listening` (outside the repo; the parts are not public).

### 2. LT-1 length change (spec §7.1)

Folder `LT-1<Role><part>`: `ref_original`, `stretch_default_<r>x`, `stretch_cheaper_<r>x`, `ref_repitch_<r>x` for r =
0.5, 0.75, 1.5, 2, 4. `LT-1lind` holds default-vs-cheaper pairs as `_A`/`_B` with the answers in `key.csv`.

1. Listen blind to `LT-1lind` on monitors and on headphones; note which of A/B you prefer per pair, then compare
   with `key.csv`.
2. Per part, listen for transient smear on punches, phasiness or metallic tails, pre-echo, low-end loss, level
   change, against `ref_original` and `ref_repitch`.
3. Load a few stretched settings into the dev editor inside a full stacked kick (row Stretch slider).
4. **Pass:** no audible transient smear on punches between 0.75× and 1.5×; tails usable between 0.5× and 2×.
5. Record per role: pass/fail, the chosen preset (default or cheaper). If punches fail, the spec says: punch layers
   default to Repitch and Bungee is evaluated.

### 3. LT-2 transposition quality (spec §12)

### 4. AC-5 fallback audibility (spec §12)

Folder `AC-5lind`: per part and interval (±1, ±5, ±12 st) a pair `_A`/`_B`, one the cached hit, one the first hit
through the real-time Repitch fallback (which also changes the length). Listen blind, note which one you think is the
fallback and whether the difference matters for a first hit; then compare with `key.csv`.

## Assumption checks AC-1–AC-4 (task 1.16)

Measured 2026-10-19 on the dev machine (AMD Ryzen 9 7945HX, Release build) with `klay_tests "[bm]" -s`
(`tests/plugin/AssumptionChecks.cpp`; also part of `ctest`). Synthetic fixture parts; one follow bus = the body on
Main, three = body (Main), crunch (A1), rumble (A2), plus a fixed transient.

| Check | Target | Result | Verdict |
| --- | --- | --- | --- |
| AC-1 cache RAM (NFR-014) | ≤ 128 MB per instance | Per cached note: buses × kick length × 8 bytes. Root ±12 (24 notes) fits in every case up to a 1/2-note kick (worst 52.7 MB: 96 kHz, 1/2, 3 buses); 1 bar at 96 kHz with 3 buses needs 105.5 MB. The whole 0–127 range exceeds 128 MB from 1/2 note at 44.1 kHz with 3 buses (128.2 MB) up to 558 MB (1 bar, 96 kHz, 3 buses): there the LRU cap evicts (UT). | Pass; cap confirmed as needed |
| AC-2 cache build time (NFR-015) | root ±2 < 100 ms, ±12 < 1 s | 48 kHz, 1/4 at 150 BPM: ±2 in 45 ms (1 bus) / 46 ms (3 buses); ±12 in 287 / 293 ms; all 127 notes in 1.5 / 1.6 s (~12 ms per further note). | Pass |
| AC-3 playback CPU (NFR-002, playback part) | whole plugin < 5 % of one core | 48 kHz / 128 samples, a kick every 400 ms, 3 follow buses + fixed: 0.04 % cached, 0.14 % through the Repitch fallback. FX chains (M4) are not in yet. | Pass for M1 |
| AC-4 latency (FR-125, NFR-003) | 0 added samples | Note-on at sample 37 → first output sample at 37, for a cached and for a fallback note (processor level). | Pass |

Design changes these checks drove: the cache shifts the buses of a note in parallel (±2 with 3 buses took 130 ms
before), and the exact-pitch method (time-stretch + Repitch) is limited to a 0.25–4× internal stretch (about ±24 st);
farther notes use Signalsmith's own pitch shift, which cut the full-range build from 46 s to 1.5 s.

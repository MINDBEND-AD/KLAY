## Decisions for the PO (made where the spec is open; each is small to change)

1. **Bin (FR-112 "clears the layer to empty"):** the bin removes only the layer's sample. Name, role, fader,
   envelope, offset, trims, mode values, routing and switches stay, so a Reforge on the empty card draws into the same
   settings. Alternative: reset the whole layer to its defaults (name and role kept).
2. **Rolls keep the trims:** FR-141 lists what stays; start and end trim are not on that list, and they are kept too
   (a roll replaces only the sample).
3. **Empty pool:** a layer in the roll whose role has no samples is left as it is (not emptied); the dev editor
   reports it ("empty pool on layer N").
4. **Library folder (decision 5):** set once with **Library...** in the dev editor; it is stored in
   `%APPDATA%\MINDBEND AD\Klaymore\library-path.txt`. The environment variable `KLAY_LIBRARY_PATH` overrides it. Files
   directly in a role folder count (the current staging folder has no sub-folders).
5. **Undo:** a host restoring its session (opening a project) clears the undo history; loading a kick JSON in the dev
   editor is one undoable step. Layer selection is not undoable and not saved.

## Manual checks (these close 2.7 and the M2 exit)

Report results by step number. The volume envelope part of UC-2 has no control in the dev editor (the envelope
editor is task 3.6 in M3); UC-2 is re-run on the real UI in `docs/checks/M3.md`.

### 0. Setup

1. Build Release (`cmake --build --preset release`) and install the plugin as in `docs/checks/M0.md` steps 1–2.
2. Open one DAW from decision 2 (Ableton Live, Reaper or FL Studio), add Klaymore on a MIDI track and open its editor.
3. Click **Library...** and choose `C:\dev\KLAY-samples`. The line under the buttons shows the folder and the number
   of samples; "(scanning...)" disappears after a few seconds (first scan only).
   Expected: the count equals the number of audio files in the six role folders; no "unreadable" count.

### 1. UC-1 Roll a kick

1. Click **Forge**. Expected: layers 1–3 (Kick, Rumble, Drive) show new sample names, layers 4–6 stay empty; the roll
   line names the seed and "new sample on layer 1,2,3".
2. Play MIDI notes and click **Audition** (or press space with the editor focused). Expected: the new kick plays at
   once after Forge, no noticeable wait (target < 100 ms), no clicks.
3. Click **Forge** 10 times, auditioning in between. Expected: every roll changes layers 1–3; a layer never gets the
   same sample twice in a row (when its role has more than one sample); each sample comes from its role's folder (hover
   a sample name to see its path).
4. Note the seed shown in the seed field, Forge twice more, type the noted seed back and click **Forge seed**.
   Expected: the kick from the noted roll comes back (same three samples).
5. Press **Undo** three times, then **Redo** three times (or Ctrl+Z / Ctrl+Shift+Z). Expected: each step goes back or
   forward one roll, the sound follows.

### 2. UC-2 Refine a layer

1. Click a layer row. Expected: that row is highlighted (selected); layer 1 is selected when the editor opens.
2. Click **↻** on layer 4 (Crunch). Expected: only layer 4 gets a sample, from the Crunch folder; it becomes selected.
3. Swap a sample by hand with **Load** on layer 2. Expected: the chosen file plays in layer 2.
4. Turn on **L** (lock) on layers 1 and 2, then **Forge**. Expected: layers 1 and 2 keep their samples, layer 3 changes;
   the roll line says "locked 1,2"; their **↻** and **Bin** buttons are disabled.
5. On layer 3: drag the offset, switch to **Pitch** and turn the knob, drag the fader. Expected: each change is heard;
   each drag is one undo step (Undo once reverts the whole drag).
6. Forge again. Expected: layer 3 gets a new sample but keeps the offset, Pitch value and fader from step 5.
7. Mute layer 1 and 3, then Shift+click any **M**. Expected: all layers unmuted. Solo layer 2, then Solo layer 3:
   only layer 3 is heard; Shift+click Solo on layer 2: layers 2 and 3 are heard.
8. Unlock layer 2 and click **Bin** on it. Expected: the layer is empty and silent, its other settings stay; Undo
   brings the sample back.
9. Double-click a layer name, type a new name, press Enter. Expected: the name changes; an empty name restores the
   default name.
10. Set layer 6's role to **Any** and click its **↻** several times. Expected: samples from any role folder.
11. In **Roll template**, turn on 4 and turn off 1, then Forge. Expected: layers 2, 3 and 4 change, layer 1 does not.

### 3. Recall and startup

1. Save the project, close the DAW, reopen the project. Expected: the kick sounds the same, the library line shows the
   sample count at once (index from the cache, NFR-008), Forge works immediately.
2. Rename or touch one sample file in `C:\dev\KLAY-samples`, close and reopen the editor's plugin instance (or the
   project). Expected: the count is right again after the short re-check; Forge still draws from all files.
